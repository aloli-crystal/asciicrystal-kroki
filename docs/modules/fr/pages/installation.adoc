= Installation

== En tant que Bibliotheque

Ajouter dans votre `shard.yml` :

[source,yaml]
----
dependencies:
  asciicrystal-kroki:
    github: aloli-crystal/asciicrystal-kroki
    version: "~> 0.10"
----

Puis executer `shards install`.

== Binaire CLI

[source,bash]
----
git clone https://github.com/aloli-crystal/asciicrystal-kroki.git
cd asciicrystal-kroki
shards build --release
ln -s "$PWD/bin/asciicrystal-kroki" ~/bin/
----

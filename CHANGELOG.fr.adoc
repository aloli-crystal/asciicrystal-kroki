== v0.10.2.2 — 2026-04-22

* Correction de la compilation du binaire `crystal-asciidoctor-kroki` :
  ajout de `require "html"` dans `extension.cr`. Le code utilisait
  `HTML.escape` sans importer le module `html` de la stdlib, ce qui
  passait inaperçu car la CI ne lançait que les specs et le linter,
  jamais un `shards build` complet de la cible binaire.

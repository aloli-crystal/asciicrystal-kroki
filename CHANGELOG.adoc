== v0.10.2.2 — 2026-04-22

* Fix compilation of the `crystal-asciidoctor-kroki` binary: add
  `require "html"` in `extension.cr`. The code was using `HTML.escape`
  without importing the stdlib `html` module, which went unnoticed
  because the CI only ran specs and the linter, never a full
  `shards build` of the binary target.
